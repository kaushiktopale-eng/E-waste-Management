## An Object-Oriented Approach to Sustainable E-Waste Management

A C++17-based offline console application for structured e-waste registration, classification, condition assessment, recycling recommendations, reward calculation, collection tracking, reporting, and file-based data persistence.

## Project Overview

This project applies Object-Oriented Programming concepts to a practical e-waste management problem. It provides a systematic workflow from e-waste registration and classification to collection and recycling.

## Key Features

- E-Waste Registration
- Automatic Classification
- Condition Assessment
- Recycling Recommendations
- Reward Point Calculation
- Collection Lifecycle Tracking
- Search and Reporting
- Exception Handling
- File Persistence
- Transaction Logging

## OOP Concepts Used

- Encapsulation
- Abstraction
- Inheritance
- Runtime Polymorphism
- Exception Handling
- STL Containers
- File Handling
